## Feature: key counter on the table (branch feature/key-counter)
- Count is drawn on the brown table in the sprite (CatView.drawCounter; table rect hardcoded as fractions of the
  Text is "Boops: N", centered in the lower body of the table (below the lip line).
  256px sprite, so custom sprites with a table elsewhere will misplace it).
- Every non-repeat keyDown = +1; Backspace (keycode 51) = -1, clamped at 0; held Backspace keeps decrementing,
  held other keys count once. Mouse clicks don't count. Forward-delete (fn+delete) counts as +1.
- Why net count: Backspace -1 means the number approximates characters currently typed, per the request.
- Privacy: the tap now reads the keycode, but only compares it to Backspace; nothing is stored or logged.
- Not persisted: resets on launch or via menu "Reset Counter". Open question: persist across launches / daily reset?

## Windows 11 port (branch feature/windows-port)
- Decisions (agreed in PRD): Python 3 + PySide6 + pynput, lives in `windows/`, shares the macOS sprites folder
  (single copy of the art), exe build script from the start (PyInstaller via `windows/build_exe.ps1`).
- Why PySide6 over tkinter: per-pixel alpha (tkinter only has a colour-key transparency with jagged edges);
  QSystemTrayIcon for the menu. Why pynput: global hooks without admin; parity with the macOS listen-only tap.
- Parity with macOS: same skins/ids/startup order, same counter rules, same text area on the table, same menu.
  Differences: settings in JSON at %APPDATA%\CatCompanionOverlay\settings.json (macOS uses UserDefaults); counter
  text is Segoe UI; no permission prompt (Windows has none for input hooks).
- Gotchas: (1) hooks don't see keys while an elevated window has focus (OS limitation); (2) pynput has no
  auto-repeat flag, so repeats are inferred (press without release within 1.5 s); (3) Qt flag
  `WindowDoesNotAcceptFocus` stops clicks on the cat stealing focus; changing `WindowStaysOnTopHint` hides the
  window, so `set_always_on_top` re-shows it only if it was visible; (4) unsigned onefile exe may trip antivirus.
- Verified on macOS only: pure-logic unit tests and Qt smoke tests run headless (windows/tests/test_qt_smoke.py: renders every skin, checks transparency and
  counter text, drives the menu/skin/counter wiring with the input hook stubbed). PySide6-Essentials 6.12.0, pynput 1.8.2.
  NOT verified: the real window, transparency, tray, hooks and the exe on Windows 11. Needs a test pass there.
